# DeviceClean
Erase traces of modifications and bypass automatic bans from Nintendo

# 使用方法(日本語)
DeviceClean.nroを`SD/switch/`に入れる  
起動し、Aボタンを押してクリーンする  

# 概要
Haku33を参考にしていますが、DeviceCleanは初期化が不要です  
これは既存の改造の痕跡を消すものであり、BANを解除、完全に回避するものではありません。（既存の痕跡は消すためその痕跡による自動BANは回避可能)  
Sysnandでのみ有効です、本来、emunandは永遠にオフラインであるべきで、オンラインに接続すべきではありません。  
DeviceCleanによってbanが引き起こされることはありません  

# English
Place DeviceClean.nro in `SD/switch/`  
Launch it and press the A button to perform the cleanup.  

# overview  
I am using Haku33 as a reference, but DeviceClean does not require initialization.  
This tool removes traces of existing modifications; it does not lift an existing ban or guarantee complete immunity from future bans (though it does prevent automatic bans triggered by those specific traces).  
It is effective only on SysNAND; ideally, EmuNAND should remain offline at all times and never connect to the internet.
